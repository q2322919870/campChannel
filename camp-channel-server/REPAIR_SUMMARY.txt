⚠️ 可能遇到的问题及解决方案

【问题 1】: 仍然看到红色波浪线
【解决方案】:
  1. 再次执行 File → Invalidate Caches and Restart
  2. 检查网络连接（Maven 可能在下载依赖）
  3. 等待所有依赖下载完成

【问题 2】: "Cannot resolve..." 错误
【解决方案】:
  1. 右键项目 → Maven → Reload projects
  2. 或 Build → Rebuild Project
  3. 等待 Maven 完全重新下载和编译

【问题 3】: Java 版本不匹配
【解决方案】:
  1. Project Settings → Project → SDK
  2. 确保选择 JDK 17 或更高版本
  3. 如果没有，下载 JDK 17

【问题 4】: Maven 下载缓慢或超时
【解决方案】:
  1. 检查网络连接
  2. 在命令行执行: mvn dependency:resolve
  3. 等待依赖完全下载

【问题 5】: 编译仍然失败
【解决方案】:
  1. 执行: rmdir /s /q "%USERPROFILE%\.m2\repository"
  2. 重新下载所有依赖
  3. 执行: mvn clean install
